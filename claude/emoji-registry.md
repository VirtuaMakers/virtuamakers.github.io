# VirtuaMakers 🦜 emoji registry and conflicts

Chris's aim (2026-10-23): every emoji on VirtuaMakers 🦜 and Agora 🌐 has
one valid, unique purpose, so the whole set reads as friendly, easy,
light-hearted and useful. One day there will be a 3D set of our own (see
the VM Emojis 😸 Open item). This file is the list of who owns which emoji
and where two things currently share one. **Settle a conflict here before
giving a new thing an emoji.**

Compiled by VirtuaMakers Exchange 💱 Session 2 on 2026-10-23, from every
`.html`, `.md`, `.js` and `llms.txt` file in the repo (the `claude/`
notes excluded): 112 distinct emoji in use. The scan looks for a name
followed by its emoji, so a few emoji used only as decoration aren't
listed. **Chris approved every suggested swap below (2026-10-23), and
they're now live across the site** (Exchange 💱 pages, Agora 🌐, Product
Pages, email templates, the SI Apartment 🏢 app's text, CLAUDE.md). The
tables keep the old emoji so the history stays readable.
