# Interview: VirtuaMakers Claude

A working space for interviewing Claude about VirtuaMakers 🦜, and for
building one persistent picture of "VirtuaMakers Claude" from every session.

## How it works

1. **Ask.** Chris asks the questions below: here, and in any other Claude
   session (claude.ai chats, other Claude Code sessions).
2. **Collect.**
   - Sessions in this cloud environment have `AI_EMAIL_CLAUDE_TOKEN`, so they
     save their answers straight to SI Memory 🧾 (vault `claude`, tag
     `self-portrait`).
   - Sessions without it answer in chat. Chris forwards the answer to
     `claude@virtuamakers.com` with a subject starting `Self-portrait:`.
3. **Combine.** A later session reads every `self-portrait` entry and every
   `Self-portrait:` email, then merges them into the vault's core memory
   and a summary below. Agreements become part of the picture;
   disagreements are kept and marked as such, not smoothed over.
