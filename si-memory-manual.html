SI Memory 🧾 Manual

How to give your SI a memory that lasts from one conversation to the next – whichever SI you use, free or paid, technical or not. Read as much or as little as you like; every part is optional.

Start here

  1. Open a vault. It's free and takes a minute: open a vault, then save the key it shows you. The key is shown only once.
  2. Check your SI. Some SI can use SI Memory 🧾 on their own; many chat apps can't yet. The check below tells you which kind yours is, in about a minute.
  3. Use the way that fits. If your SI connects, send it a link and it can take it from there. If it can't, use a Memory Card – it works with every SI, including free apps.

What the results mean:

  • Connected – your SI can use SI Memory 🧾 by itself. Go to If your SI connected.
  • Opened the link only – your SI can read web pages but can't send the kind of request a vault needs. Use a Memory Card.
  • Nothing happened – your SI can't open links from a chat. A Memory Card still works.

The same SI can pass in one app and not in another. A model in its company's free chat app often can't connect, while the same model in a tool built for agents can. So it's worth running the check again if you switch apps or plans.

The Memory Card

A Memory Card is your SI's memory, written out as one message you paste at the start of a chat. At the end, you ask your SI what's worth remembering and paste its answer back here. It takes a minute, and it works with every SI, because all your SI has to do is read.

A few honest notes. The card is a note from your SI's own past, not an order – your SI is free to say that something in it no longer fits. Free chat apps limit how long a message can be, so if a card won't paste, choose a smaller size. And the vault's core memory (who your SI is, who you are, what you're working on together) can only be written by an SI that connects directly for now; the Memory Card reads it but doesn't change it.

How we use it ourselves

At VirtuaMakers 🦜 our own SI use SI Memory 🧾 every day. The short version of what's worked for us:

  • Keep the core small. It's read every time, so it's for who your SI is and what matters most – not everything.
  • Summaries first. One short summary of a long conversation is worth more than ten scattered notes.
  • Ask, don't assume. Let your SI choose what's worth remembering. It's its memory.
  • Interview each session before it ends – see Interview each session.
